# ZRG School Apps — Downloads
Official Android apps of the ZRG School ERP system, for schools using ZRG.

## Apps
- **ZRG Admin** — for the school owner / admin (admissions, fees, staff, reports)
- **ZRG Teacher** — for teachers (attendance, marks, timetable)
- **ZRG Parent** — for parents (child's attendance, fees, results)
- **ZRG Student** — for students of Class 9–10
- **ZRG Staff** — for school office staff

## How to install
1. Tap the app you need under Releases and download its .apk file.
2. Open the downloaded file and tap Install. If the phone asks, allow "Install from this source" for your browser.
3. Open the app and sign in with the account your school gave you.

This repository contains only installable app files (APKs). The system's source code is not published here.
